끌다가 멈추면 네 갈래가 열려요. 조합키 ⇧ ⌃ ⌥ ⌘를 톡 누르면 원하는 갈래로 바로 가요.

⇧ 변환

형식을 바꿔요.

JPG, PNG, WEBP, HEIC, TIFF, BMP, PDF. 오디오: MP3, M4A, WAV, FLAC, OGG, OPUS, AIFF, WMA. 영상: MP4, MOV, MKV, AVI, WMV, GIF, WEBM 입력과 같은 일곱 형식 또는 MP3 오디오 추출. 원본은 그대로 두고, 새 파일은 바로 옆에 만들어요.

⌃ 동작

파일을 보내요.

AirDrop, 공유, 띄워 두기, 복사, 이동, 경로 복사, 훑어보기, 다음으로 열기, 터미널. 어떤 파일이든 같은 아홉 칸이에요.

⌥ 프리셋

팀의 설정을 한 번에.

Web JPG처럼 팀이 정한 변환이에요. .orangepreset 파일을 두 번 누르면 추가돼요.

⌘ 도구

이미지·오디오·영상을 다듬어요.

이미지 7가지: 압축, 메타데이터, 편집, 주석, 배경 추가, 자르기, 가리기오디오 5가지: 압축(Compress), 메타데이터(Metadata), 구간 자르기(Trim), 음량 맞추기(Normalize), 채널(Channels)영상 8가지: 압축, 메타데이터, 구간 자르기, 음소거(Mute), 분할(Split), 자르기(Crop), 속도(Speed), 장면 저장(Snapshot)원본은 그대로 두고, 결과는 다시 확인한 뒤 옆에 저장해요.

  • 1.4.4

    폴더에 넣을 때 휠이 끼어들지 않아요.

    Finder 창의 빈 자리에서 멈추면 휠이 열리고, 손쉬운 사용 권한으로 폴더·사이드바·Dock 아이콘 위는 피하며 시작하기와 업데이트 직후에 권한을 한 번 물어봐요. 할 수 없는 일과 저장 문제의 안내가 더 분명해졌고, 읽기 전용 디스크의 결과는 다운로드 › Orange에 저장하며 느린 디스크에서도 Orange가 멈추지 않아요.

    • 폴더에 파일을 넣으려고 잠깐 멈춰도 휠이 끼어들지 않아요. Finder 창에서는 빈 자리에서 멈추면 열리고, 폴더·사이드바·Dock 아이콘 위에서는 열리지 않아요. 이 구분에 손쉬운 사용 권한을 쓰고, 시작하기와 업데이트 직후에 한 번 물어봐요.
    • 손쉬운 사용 권한이 없으면 Finder 창 위에서는 멈춰도 휠이 열리지 않아요. 설정 › 일반 › 휠에서 언제든 허용할 수 있고, 조합키를 톡 누르면 어디서나 열려요. 'Finder와 바탕화면에서만'은 'Finder에서'로 이름이 바뀌었어요.
    • 테마 파일을 설정 › 테마나 시작하기 창에 끌어 놓으면 다시 바로 설치돼요. Orange 창 위에서는 다른 앱에서 끌어 온 파일에 휠이 열리지 않아요.
    • 결과함이나 띄운 카드의 결과 파일을 다시 휠로 끌어 놓을 수 있어요.
    • 휠 가운데에서 손을 떼면 휠이 바로 사라지고, 파일이 뒤에 있는 창으로 떨어지지 않아요. 떨어지지 않게 하는 데는 손쉬운 사용 권한을 써요.
    • Safari 이미지처럼 아직 파일이 아닌 것을 끌면 "먼저 파일로 저장한 다음 끌어 주세요."라고 알려 줘요.
    • 할 수 없는 일을 요청하면 이유를 알려 줘요. 여러 음원·영상에는 한 번에 할 수 있는 도구만 보이고, 문서는 한 번에 100개·합계 10GB까지라고 미리 알려 줘요.
    • 원본이 읽기 전용 디스크에 있으면 결과를 다운로드 › Orange에 저장하고 알려 줘요. 저장하지 못하면 권한 문제인지, 공간이 부족한지 구분해서 알려 줘요.
    • 느린 네트워크 디스크나 외장 디스크를 써도 Orange가 멈추지 않아요. 결과함의 취소를 누르면 남은 준비와 확인 창까지 한 번에 멈춰요.

  • 1.4.3

    Liquid Glass로 새로워진 휠을 만나 봐요.

    휠이 더 작아지고, macOS 26 이상에서는 Liquid Glass로 보여요. 가는 원 두 개로 차분해졌어요. 안쪽 원에서 갈래를 고르고, 둥근 아이콘 위로 포인터를 옮기면 도구 이름이 가운데에 크게 보여요. 화면 가장자리나 모서리에서는 도구가 빈 쪽으로 돌아서 보여요. Force Touch 트랙패드의 가벼운 진동과 새 테마 Dark, Bold, Pastel도 만나 봐요.

    • 휠이 더 작고 차분해졌어요. 가는 원 두 개가 있고, 안쪽 원에는 작은 갈래 버튼이 있어요.
    • 도구는 둥근 아이콘으로 보여요. 포인터 아래 도구의 이름은 가운데에 크게 보여요.
    • macOS 26 이상에서는 휠이 Liquid Glass로 보여요. 갈래 버튼, 가운데 판, 둥근 아이콘이 모두 유리예요.
    • 파일을 끌다가 어디서든 잠깐 멈추면 휠이 열려요. 멈추는 동안 주황색 링이 차올라요.
    • 가리기와 프리셋 아이콘을 알아보기 쉬워졌어요. 프리셋은 결과 형식(JPG, PNG 등)으로 구분돼요.
    • 도구를 향해 움직이기 시작하면 갈래가 그대로 있어요. 옆 갈래로 잘못 넘어가지 않아요.
    • 화면 가장자리나 모서리에서도 휠이 화면 안에 다 들어오고, 도구는 빈 쪽으로 돌아서 보여요.
    • Force Touch 트랙패드에서는 휠이 열릴 때, 갈래가 고정될 때, 도구 사이를 움직일 때 가벼운 진동이 전해져요.
    • Dark, Bold, Pastel 세 가지 테마가 새로 생겼어요. 설정 › 테마에서 골라요.

  • 1.4.2

    여러 사진을 한눈에 살펴봐요.

    여러 사진이나 폴더를 도구 › 썸네일 모음에 놓으면 파일 이름이 붙은 썸네일을 PDF 하나로 모아요. 읽을 수 없는 파일은 이유와 함께 빈 칸으로 남기고, 첫 사진 옆에 저장해요.

    • 파일을 끌다가 멈춰 휠을 열고 도구 › 썸네일 모음에 놓아요.
    • 결과함에서 들어간 사진 수와 빈 칸 수, 읽을 수 없는 파일의 이유를 확인해요.
    • PDF는 첫 사진 옆에 저장해요. 폴더에 쓸 권한이 없으면 ~/Downloads/Orange에 저장하고 결과함에서 알려 줘요.
    • 설정에서 용지, 격자, 정렬, 세부 정보를 골라요. 한 번에 최대 500장의 사진을 모을 수 있어요.
    • 사진이 2개 이상이면 도구 갈래가 9칸으로 보여요. 사진 1개를 놓으면 8칸으로 보여요.

  • 1.4.1

    사진 속 글자를 꺼내요.

    사진과 스크린샷의 영어·한국어 글자를 이 Mac에서 TXT 또는 Markdown으로 저장해요. 여러 파일과 폴더도 한 번에 처리하고, 결과는 원본 옆에 만들어요.

    • 파일을 끌다가 멈춰 휠을 열고 도구 › 글자 추출에 놓아요.
    • 결과는 원본 옆에 만들어요. 원본이 여럿이면 첫 원본 옆에 저장해요. 폴더에 쓸 권한이 없으면 이 Mac의 다운로드 폴더인 ~/Downloads/Orange에 저장하고 결과함에서 알려 줘요.
    • 결과함에서 글자 수를 확인해요. 인식이 불확실한 줄이 많으면 ‘검토 필요’를 보여 줘요. 원본과 비교한 뒤 ‘텍스트 복사’로 다른 곳에 붙여 넣어요.
    • 이 Mac에서 글자 인식을 사용할 수 없으면 글자 추출 칸을 흐리게 보여 주고 이유를 알려 줘요.
    • 도구 갈래에 글자 추출 칸이 더해져 8칸이 돼요.

  • 1.4.0

    끌다가 멈추면 휠이 열려요.

    네 갈래 휠에서 할 일을 골라요. 사진 크기와 저장 방법을 프리셋으로 저장하고, 폴더와 여러 파일도 한 번에 처리해요. 결과는 원본 옆에 만들어요.

    • Finder나 바탕화면에서 파일을 끌다가 0.5초 멈추면 휠이 열려요. 키를 누르지 않아도 돼요.
    • 하나의 휠에 변환·도구·동작·프리셋 네 갈래가 모였어요. 원하는 갈래로 끌어간 뒤 할 일 칸에 놓아요.
    • 키는 빠른 길이에요. 끌면서 톡 누르는 기본 키는 ⇧ 변환, ⌘ 도구, ⌃ 동작, ⌥ 프리셋이에요. 설정 › 일반에서 바꿀 수 있어요.
    • 휠이 열리면 뒤 화면이 어두워져요. 휠 밖에 놓으면 아무 일도 일어나지 않아요. 가운데에 놓으면 취소해요.
    • 휠에서 멀리 끌면 닫혀요. 그 끌기에서는 멈춰도 다시 열리지 않아 평소처럼 파일을 옮길 수 있어요.
    • 설정 › 일반 › 휠의 ‘멈추면 휠 열기’는 끔·Finder와 바탕화면에서만·어디서나 중 골라요. 기본은 Finder와 바탕화면이에요. ‘멈추는 시간’은 0.3초·0.5초·0.7초 중 고르고 기본은 0.5초예요.
    • 같은 곳에서 ‘휠 크기’와 ‘휠 뒤 화면 가리기’를 바꿔요. 기본은 보통 크기와 가리기 켬이에요. 손가락으로 쓰려면 ‘크게(터치용)’를 골라요.
    • 사진 크기와 저장 방법을 프리셋으로 저장해요. 긴 쪽의 최대 길이·형식·품질을 정하고, 작은 사진은 키우지 않아요. 프리셋이 하나 이상 있어야 ⌥로 열려요.
    • ‘어디서나 같은 색으로 보이게 (sRGB)’도 고를 수 있어요. 사진 정보는 ‘찍은 곳만 지우기’·‘모두 남기기’·‘모두 지우기’ 중 골라요.
    • 프리셋의 ‘사진에 글자 넣기’로 최대 40자의 글자를 넣어요. 글자 자리·크기·진하기를 골라요. 사진이나 글자를 넣을 자리가 너무 작으면 글자 없이 저장할 수 있어요.
    • 변환·도구·프리셋은 폴더 안의 폴더도 찾고, 폴더 안의 숨은 파일은 건너뛰어요. 동작은 폴더를 펼치지 않고 놓은 항목을 그대로 받아요.
    • 변환·도구·프리셋은 최대 500개까지 처리해요. 넘으면 시작 전에 처음 500개만 할지 취소할지 물어요. 일부 도구는 20개나 100개까지 받으며 칸에서 알려 줘요.
    • 이 세 갈래는 폴더에서 가장 많은 파일 종류를 골라요. 사진 10개와 영상 1개면 영상은 건너뛰고 결과함에 이유를 알려 줘요. 처리할 수 없는 파일도 이유와 함께 건너뛰어요.
    • 메일 첨부 파일처럼 시스템 임시 폴더(/var/folders)에서 받은 문서·사진·영상·음악을 처리할 때 ‘확인하지 못했어요’라며 멈추던 문제를 고쳤어요.
    • 결과는 원본과 같은 폴더에 복사본으로 저장하고 원본은 그대로 두어요. 원본이 여럿이면 첫 원본 옆에 저장해요. 쓸 권한이 없으면 이 Mac의 다운로드 › Orange에 저장하고 결과함에서 알려 줘요.
    • 알려진 점: Finder에서 파일을 끌다가 폴더 위에 멈춰도 휠이 열릴 수 있어요. 그 폴더에 넣으려면 휠에서 멀리 끌어 닫은 뒤, 다시 폴더로 가져가 놓아요.

  • 1.3.3

    변환한 복사본을 원본 옆에 만들어요.

    이미지·미디어·문서 결과를 원본과 같은 폴더에 저장해요. 쓸 권한이 없으면 로컬 다운로드 › Orange에 저장하고 결과함에서 알려 줘요.

    • 이미지·미디어·문서를 변환하면 원본과 같은 폴더에 복사본을 만들어요. 원본은 그대로 두어요.
    • PDF 합치기와 여러 파일 압축처럼 원본이 여러 개인 결과는 첫 번째 원본의 폴더에 저장해요.
    • 같은 이름이 있으면 이름 뒤에 숫자를 붙여요.
    • iCloud Drive와 iCloud 데스크탑·문서에서도 다운로드가 끝난 원본 옆에 저장해요. iCloud에만 있는 파일은 Finder에서 ‘지금 다운로드’를 선택한 뒤 다시 시도해 주세요.
    • 원본 폴더에 쓸 권한이 없으면 iCloud가 아닌 로컬 다운로드 › Orange의 분류 폴더에 저장하고 결과함에서 알려 줘요.
    • 설정에서 대체 저장 위치를 확인할 수 있어요. 폴더 선택은 없애고 다운로드 › Orange를 사용해요.
    • 같은 파일을 같은 도구·출력 형식으로 다시 변환해 성공하면 결과함의 이전 실패 줄은 자동으로 사라져요. 다른 실패 줄은 ‘닫기’를 누를 때까지 남아요.
    • 분류 폴더 이름은 처음 만들 때 Mac의 언어로 정해요. 나중에 언어를 바꿔도 이름은 그대로예요.
    • 예전에 만든 결과는 옮기지 않아요. 설정에서 ‘이전 결과 열기’로 찾을 수 있어요.

문제가 생기면.

인텔 Mac에서 열리지 않아요

Orange는 Apple 실리콘(M1 이상) Mac 전용이에요. 인텔 Mac에서는 macOS가 '이 Mac에서 지원되지 않는다'고 알려 주고 열리지 않아요.

1.2.0 미디어의 제한은?

한 번에 한 파일을 로컬에서 편집해요. 클라우드 제공자 파일은 로컬 폴더로 복사하세요. 형식에 따라 미리 재생할 수 없거나 Metadata가 보기 전용이며, 목표 용량을 맞출 수 없으면 이유를 안내해요. HDR→SDR 변환은 밝기·색 손실을 먼저 확인해요. HDR10+와 Dolby Vision profile 5의 색 처리는 실제 기기 영상 없이는 검증되지 않았어요. Dolby Vision profile 5와 12-bit 입력은 지원하지 않아요. Mute의 HDR 보존은 재인코딩 없는 호환 컨테이너에 한해요. VoiceOver를 먼저 켜면 응용 프로그램 선택기에 Orange가 안 보일 수 있어요(1.1.0부터). 편집 창은 사용할 수 있고, 창을 연 채 VoiceOver를 껐다 켜면 목록에 나타나요.

미디어 라이선스와 소스는?

FFmpeg, LAME, Opus, Ogg, Vorbis, libvpx, dav1d, zimg 및 IJG, zlib, WTFPL 고지와 전문을 About에서 오프라인으로 읽어요. 대응 소스·재링크 자료와 SHA256SUMS는 1.2.0 릴리스 다운로드에 함께 제공해요.

휠이 뜨지 않아요

Finder나 바탕화면에서 마우스 단추를 누른 채 파일을 끌다가 잠깐 멈추세요. Finder 창에서는 빈 자리에서 멈추고, 설정 › 일반 › 휠에서 손쉬운 사용 권한을 허용하세요. 폴더·사이드바·Dock 아이콘 위에서는 열리지 않아요. ‘멈추면 휠 열기’는 끄기 / Finder에서 / 어디서나 중 고르고, 기본은 어디서나예요. 조합키를 짧게 한 번 톡 눌러도 열려요. 누르고 있으면 톡이 아니에요. Tangerine처럼 조합키로 휠을 여는 다른 앱이 켜져 있으면 그 앱을 끄거나, 설정 › 일반에서 Orange의 조합키를 바꾸세요.

폴더를 쓸 수 없다고 나와요

시스템 설정 › 개인정보 보호 및 보안 › 파일 및 폴더에서 Orange 아래의 그 폴더를 켜세요. 시작하기 셋째 쪽의 설정 열기도 같은 화면을 열어요.

⌃⌥O를 눌러도 휠이 안 떠요

Finder에서 파일을 먼저 고르세요. Finder 선택을 볼 수 없다고 나오면 시스템 설정 › 개인정보 보호 및 보안 › 자동화에서 Orange 아래의 Finder를 켜세요. 다른 앱이 같은 단축키를 쓰면 설정 › 일반에서 바꿔요.

“응용 프로그램 폴더로 옮겨 주세요”가 계속 떠요

DMG 안이나 받은 폴더에서 켠 상태예요. Orange를 끄고 응용 프로그램 폴더로 옮긴 뒤 거기서 켜세요. 그래야 업데이트도 받아요.

지우고 싶어요

메뉴에서 Orange를 끄고, 응용 프로그램 폴더의 Orange를 휴지통으로 옮기면 돼요.
