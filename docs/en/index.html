DragTapDrop

Four wheels.

Each modifier key opens its own wheel. Try ⇧ ⌃ ⌥ ⌘ on your keyboard.

⇧ Convert

Change the format.

JPG, PNG, WEBP, HEIC, TIFF, BMP, PDF. The original stays; the new file goes right next to it.

⌃ Actions

Send it somewhere.

AirDrop, Float, Copy, Move, Copy Path, Terminal. The same six for any file.

⌥ Presets

Your team's settings, at once.

Conversions your team set up, like Web JPG. Double-click an .orangepreset file to add one.

⌘ Tools

Work on images.

Drag an image and tap ⌘ to pick one of six tools: Compress (by quality or target size, no window), Metadata (view or strip location, camera, dates, or everything), Edit (exposure, contrast, saturation, warmth, sharpness), Annotate (arrows, boxes, text, highlighter, pen), Crop (ratio, rotate, flip), and Redact (opaque boxes, saved as a verified PNG). The original stays; the result is saved next to it with a suffix.

Three steps to install.

  1. Open the DMG.

    Double-click the Orange DMG you downloaded.

  2. Into Applications.

    Drag Orange onto the Applications folder next to it.

  3. Click Open.

    The first time, macOS asks. Click Open; it also says Apple checked the app.

Permissions, once.

On the third page of Getting Started, click Allow Finder Control… and Allow Folders…. Then no question interrupts your first drag.

Good to know.

When the wheel opens, move a little.

macOS picks where a drag goes when the pointer moves. If “Move to choose · Esc cancels” shows below the wheel, move slightly, then let go.

⌃⌥O

Without dragging.

Select in Finder and press ⌃⌥O. Arrow keys to choose, Return to run.

esc

To cancel.

Let go in the middle, or press Esc. Nothing happens.

Updates, with one dot.

A dot on the menu bar icon means a new version. Install it from the top of the menu; Orange opens again.

If something goes wrong.

The wheel doesn't open

Tap the modifier key briefly while you drag, with the mouse button down. Holding it isn't a tap. If another app that opens a wheel on modifier taps is running, such as Tangerine, quit it or change Orange's keys in Settings › General.

Orange can't use a folder

Turn that folder on for Orange in System Settings › Privacy & Security › Files & Folders. Open Settings on the third page of Getting Started goes there too.

Nothing happens on ⌃⌥O

Select files in Finder first. If Orange can't see the Finder selection, turn on Finder under Orange in System Settings › Privacy & Security › Automation. If another app uses the shortcut, change it in Settings › General.

“Move Orange to the Applications folder” keeps showing

Orange is running from the DMG or your Downloads folder. Quit it, move it to Applications and open it there. It can only update itself from there.

I want to remove Orange

Quit Orange from its menu and move it from Applications to the Trash.
